# Algoritmos y Estructuras de Datos

Material de los cursos CE-1103 y CE-2103 del Instituto Tecnológico de Costa Rica, en forma de presentaciones (`.pptx` y `.pdf`) en español.

**Fuente de verdad:** cada lección se define en un spec JSON en [`presentaciones/generador/specs`](presentaciones/generador/specs). Los `.pptx` y `.pdf` se generan a partir de él (no se editan a mano): modifique el spec y ejecute `presentaciones/generador/build-all.ps1`. Detalles en [`presentaciones/generador/README.md`](presentaciones/generador/README.md).
